# Proyectos en C

Aquí incluyo ejercicios y proyectos realizados en **C**. Cada archivo contiene comentarios del código además de una descripción general de lo que hace el programa.

## Compilación

Para compilar y ejecutar los programas, se puede usar el compilador gcc de la siguiente manera:

gcc -O2 "ejercicio 1.c" -o "ejercicio1.exe"
Reemplazando "ejercicio 1.c" por el nombre del ejercicio a compilar.

## Ejecución

Para ejecutarlo:

./ejercicio1.exe
